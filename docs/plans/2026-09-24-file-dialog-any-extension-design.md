# ファイルダイアログの拡張子制限撤廃 設計書

- 日付: 2026-09-24
- ブランチ: `feature/file-dialog-any-extension`
- 規模: 小変更(§3 簡略化基準を適用。実装 1 commit・最終レビュー 1 回統合)

## 目的

「開く」ダイアログが既定で `.txt / .md / .csv` に絞り込まれており、それ以外の拡張子のファイルは
「すべてのファイル」へ切り替えないと選べない。また「名前を付けて保存」の参照ダイアログは元ファイルの
拡張子にかかわらず常に「テキスト ファイル (*.txt)」が初期選択される。これを次のように改める。

- 開く: 拡張子での絞り込みをやめ、どの拡張子のファイルも最初から選択できる。
- 名前を付けて保存(参照): `.txt / .md / .csv` は対応する種類を初期選択する。
  それ以外の拡張子はファイルの種類を「すべてのファイル」にし、ファイル名に拡張子を含めたまま渡す。

## 現状

| 箇所 | 現状 |
|------|------|
| `WinFormsFileDialogService.PickOpenPath` | `Filter = "対応ファイル (*.txt, *.md, *.csv)\|*.txt;*.md;*.csv\|すべてのファイル (*.*)\|*.*"`(既定=対応ファイル) |
| `SaveAsDialog.OnBrowseClicked` | `Filter = txt\|md\|csv\|すべて` の 4 択。`FilterIndex` 未指定(=1: txt 固定)。`FileName = Path.GetFileName(_path.Text)` |

## 設計

### 1. 開くダイアログ

`Filter` を `"すべてのファイル (*.*)|*.*"` の 1 択にする。絞り込み選択肢は残さない(ユーザー判断)。

### 2. 名前を付けて保存(参照ボタン)

- `Filter` の 4 択は従来どおり。
- `FilterIndex` をテキストボックスのパスの拡張子(大文字小文字無視)から決める。

| パス | FilterIndex |
|------|-------------|
| null / 空(未保存の新規) | 1: テキスト(従来どおり) |
| `.txt` | 1: テキスト |
| `.md` | 2: マークダウン |
| `.csv` | 3: CSV |
| 上記以外(`.log` 等) | 4: すべてのファイル |
| 拡張子なし(`Makefile` 等) | 4: すべてのファイル |

- 拡張子なしを 4 にするのは、*.txt フィルタのままだと保存時に `.txt` が自動付与されるため
  (WinForms の `AddExtension` は現在フィルタの拡張子を補う。`*.*` は補完対象外)。
- `FileName` は従来どおり `Path.GetFileName(パス)`(拡張子込み)。

### 3. テスト容易化

判定ロジックを `SaveAsDialog` 内の純粋関数 `internal static int FilterIndexFor(string? path)` に切り出し、
L3(`kxEdit.App.Tests`)で上表の全行+大文字拡張子(`.MD`)+ディレクトリ付きパスを検証する。
Form 本体は自動テスト対象外(ダイアログ表示は手動確認)。

ミューテーション検証は CLAUDE.md §4.A の禁止範囲(GUI・I/O)のため実施しない。

## 意図的な挙動変更

- 開くダイアログの既定の種類が「対応ファイル」→「すべてのファイル」になり、「対応ファイル」選択肢は消える。
- 保存の参照で、元ファイルが `.md / .csv` のとき初期選択が txt → md / csv に変わる。
- 保存の参照で、元ファイルが上記以外・拡張子なしのとき初期選択が txt → すべてのファイルに変わる。

## L5 要否

SR 経路(`kxEdit.Accessibility` / `EditorControl` の UIA 部 / Speech 系)に触れないため必須ではない。
コモンダイアログの初期表示(種類・ファイル名)をユーザーに手動確認してもらう。
