# L5(実機 SR 検証)チェックリスト — Home キーの動作を設定で切り替える

対象ブランチ: `feature/home-key-behavior`
設計書: `2026-09-04-home-key-behavior-design.md` / 実装計画: 同名(`-design` なし)

**このブランチの L5 は必須**(設計書 §5)。Home はキャレット移動であり、移動先が変われば
NVDA が読み上げる位置と内容が変わる。CLAUDE.md §5 の「判定に迷ったら必要に倒す」に従う。

**判定欄は実施前なので空にしてある。** 実施時に **PASS / FAIL / N/A** を記入し、FAIL は
**聞こえた文言を逐語で**残す(要約しない)。

> ## ⚠️ 設定ダイアログが潰れて表示される(Issue #68)
>
> `オプション → 設定` のダイアログは **136×89 px に潰れて表示される既存不具合**がある
> (本ブランチとは無関係。`TabControl` がページ内容から推奨サイズを申告しないため)。
> **マウスでは操作できない。** 本チェックリストの設定操作は**すべてキーボードで行う**こと。
>
> 手順: `Alt` → `O`(オプション)→ `P`(設定)→ `Ctrl+Tab` で「編集」タブへ →
> `Tab` で各項目へ → `Enter` で OK。
>
> §5 はこのダイアログ自体の読み上げを見る節なので、**Issue #68 の修正後に再実施が要る**
> 可能性がある。実施時に潰れたままなら、その旨を判定欄に書き残すこと。

## 0. 準備

### 0.1 なぜ L5 が要るか(自動テストで届かない範囲)

| 事実 | 状況 |
|------|------|
| 移動先の offset(スマート / 常に行頭・折り返し ON の視覚行基準) | L1 `NavigationCommandsTests` で固定済み。**L5 で数え直さない** |
| 設定 → `EditorControl` → `InputRouter` の配線 | L2 `KeyboardNavigationTests` で固定済み |
| ダイアログの構造・排他・アクセスキーの一意性 | L3 `EditSettingsTabTests` で固定済み |
| **NVDA が実際に何を読むか**(移動後にどこから読み始めるか) | **自動テストでは原理的に検証不能。L5 でのみ確認できる**(CLAUDE.md §2 の a11y 鉄則) |
| 折り返し ON の継続行で**視覚行の先頭から**読まれるか | 同上。P8-1a の不変条件が両モードで保たれることの実機確認 |
| GroupBox 名「Home キーの動作」がフォーカス時に読まれるか | 同上 |

`tools/sr-regression.ps1` は **UIA 応答の検証まで**で、**実発声は検出できないため L5 の代替に
ならない**(CLAUDE.md §5)。

### 0.2 環境

- NVDA を起動し、**スピーチビューアー**を開く(PR #53 で確立した逐語検証手法)。
  聞き取りではなくビューアーの**テキストで**照合すること。
- 検証用ファイルを作る(**タブではなく半角空白 4 つ**でインデントすること。
  タブ幅設定の影響を受けないため):

  `%TEMP%\home-key-l5.txt`
  ```
  abc
      hello world
  日本語のテキストです
  ```
  2 行目は先頭に半角空白 4 つ + `hello world` で 15 文字。

- 設定の初期状態を確認しておく:「編集」タブの折り返しは **オフ**、Home キーの動作は
  **「行の最初の文字へ移動する」**(既定)。

## 1. 折り返し OFF・スマート(既定)

| # | 手順 | 期待 | 判定 |
|---|------|------|------|
| 1-1 | `home-key-l5.txt` を開き、2 行目の `world` の `r` 付近にキャレットを置く(`↓` と `→` で移動) | — | |
| 1-2 | **Home** を 1 回押す | キャレットが `hello` の `h` に来る。NVDA が**先頭空白を読まずに** `hello world` 側から読み始める(空白 4 つを「スペース スペース…」と読まない) | |
| 1-3 | 続けて **Home** をもう 1 回押す | キャレットが真の行頭(空白の前)に来る。NVDA が**空白から**読み始める | |
| 1-4 | さらに **Home** を押す | 1-2 の状態に戻る(トグルする) | |

## 2. 折り返し OFF・常に行頭

| # | 手順 | 期待 | 判定 |
|---|------|------|------|
| 2-1 | 設定を開き(`Alt`→`O`→`P`)、`Ctrl+Tab` で「編集」タブへ移動する | NVDA が「編集」タブに入ったことを読む | |
| 2-2 | `Tab` でグループ「Home キーの動作」まで進み、`↓` で「常に行頭へ移動する」を選ぶ | ラジオの選択が移り、NVDA が「常に行頭へ移動する 選択」相当を読む | |
| 2-3 | `Enter` で OK。**設定ダイアログを開いたときのタブはそのまま**にしておく | 「設定を適用しました」相当の発声(バックアップ健全性の報告があるときはそちらが優先される。設計 2026-09-02 §4) | |
| 2-4 | 2 行目の `world` の `r` 付近へ戻り、**Home** を 1 回押す | キャレットが**真の行頭**(空白の前)に来る。NVDA が**空白から**読み始める | |
| 2-5 | 続けて **Home** をもう 1 回押す | **キャレットが動かない**。1-2 のような `h` への移動は起きない | |
| 2-6 | 3 行目(`日本語の…`・インデント無し)で **Home** を押す | 行頭に来る。1 回目・2 回目とも同じ | |

## 3. 折り返し ON・常に行頭(P8-1a の実機確認)

> 設定「編集」タブで**「指定文字数で折り返す」をオン**にし、**折り返し桁数を 8** にする。
> 2 行目 `    hello world`(15 文字)が 2 つの視覚行に割れる
> (1 つ目 = `    hell` の 8 文字、2 つ目 = `o world` の 7 文字)。
> 判定の要は「**論理行の先頭へ飛ばないこと**」。

| # | 手順 | 期待 | 判定 |
|---|------|------|------|
| 3-1 | 2 行目の**2 つ目の視覚行**(`o world` 側)にキャレットを置く | — | |
| 3-2 | **Home** を押す | キャレットが**その視覚行の先頭**に来る。NVDA が**その視覚行の先頭から**読む。**1 つ目の視覚行(`    hell` 側)の先頭へは飛ばない** | |
| 3-3 | 続けて **Home** を押す | 動かない(トグルしない) | |
| 3-4 | Home キーの動作を「行の最初の文字へ移動する」に戻し、3-1〜3-2 を繰り返す | 継続視覚行では**同じく視覚行の先頭**。ここはモードによらず同じ挙動であることの確認 | |
| 3-5 | 1 つ目の視覚行(`    hell` 側)の `e` 付近で **Home** を押す | スマート = `h` へ。もう一度押すと行頭へ(1 章と同じトグル) | |
| 3-6 | 検証後、折り返しを**オフに戻す** | — | |

## 4. Shift+Home(選択の読み上げ)

| # | 手順 | 期待 | 判定 |
|---|------|------|------|
| 4-1 | Home キーの動作を**「常に行頭へ移動する」**にする。2 行目の `hello` の `o` 付近にキャレットを置く | — | |
| 4-2 | **Shift+Home** を押す | **インデントの空白を含めて**行頭までが選択される。NVDA が選択範囲を読み上げる(空白を含む) | |
| 4-3 | Home キーの動作を**「行の最初の文字へ移動する」**に戻し、4-1 の位置から **Shift+Home** | 選択が `h` までで止まり、**インデントの空白は選択されない** | |
| 4-4 | どちらのモードでも **Ctrl+Home** を押す | 文書の先頭(1 行目 `abc` の先頭)へ移動する。**設定の影響を受けない** | |

## 5. 設定ダイアログの読み上げ

> 上の警告のとおり、ダイアログは潰れて表示される(Issue #68)。**キーボードのみで操作する。**

| # | 手順 | 期待 | 判定 |
|---|------|------|------|
| 5-1 | 設定を開き「編集」タブへ移動、`Tab` でラジオまで進む | フォーカスが入った時点で NVDA が**グループ名「Home キーの動作」**を読む | |
| 5-2 | ラジオの読み上げを確認する | 「行の最初の文字へ移動する(もう一度押すと行頭)」/「常に行頭へ移動する」が読まれる。**括弧の中まで読まれて意味が通るか**を確認(冗長すぎないか) | |
| 5-3 | `↑` / `↓` でラジオを切り替える | 排他で切り替わり、選択された方だけが「選択」と読まれる | |
| 5-4 | `Alt+F` を押す | 「行の最初の文字へ移動する」が選択される。**表示タブの「変更(&F)」ボタンには反応しない** | |
| 5-5 | `Alt+B` を押す | 「常に行頭へ移動する」が選択される。**表示タブの「空白・改行文字を表示する(&B)」やバックアップタブのチェックボックスには反応しない** | |
| 5-6 | `Esc` でキャンセルし、もう一度開く | 直前に選んだ値ではなく、**保存済みの値**が選択された状態で開く | |

## 6. 後片付け

- Home キーの動作を**「行の最初の文字へ移動する」(既定)** に戻す。
- 折り返し設定を検証前の状態に戻す。
- `%TEMP%\home-key-l5.txt` を削除する。
