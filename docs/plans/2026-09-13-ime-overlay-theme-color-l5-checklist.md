# L5(実機検証)チェックリスト — IME overlay の文字色テーマ連動(Issue #72)

策定日: 2026-09-13
対象ブランチ: `feature/ime-overlay-theme-color`
ベース commit: main `50ffc39`(PR #73 = WinForms の IME モード推測無効化のマージ後)
設計書: `2026-09-13-ime-overlay-theme-color-design.md` / 実装計画: 同名(`-design` なし)

**本件の L5 は「実機 SR 検証」ではなく「実機目視」**。SR 経路(`kxEdit.Accessibility` /
`EditorControl` の UIA 部 / App の Speech 系)には触れないため、**SR の読み上げは変わらない**
(`tools/sr-regression.ps1` も不要)。一方で本件は**見た目そのものを変える**変更であり、
可読性は自動テストでは判定できない。したがって**目視が最終ゲート**になる。

**未実施。** 判定欄は空にしてある。実施時に **PASS / FAIL / N/A** を記入し、FAIL は
**見えた状態を具体的に**残す(「読みにくい」ではなく「黒地に濃い灰色で輪郭がぎりぎり見える」のように)。

## 0. 準備

### 0.1 なぜ目視が要るか(自動テストで届く範囲/届かない範囲)

**自動テストで既に固定されている事実(L5 で確かめ直さない)**

| 事実 | 網 |
|---|---|
| `ApplyAppearance` 後、overlay の通常節色がテーマ前景と一致すること(4 テーマ) | L2 `ImeOverlayColorTests.OverlayForeColor_FollowsThemeForeground` |
| 対象節色が全テーマで黒のままであること(+ テーマが実際に効いているアンカー付き) | 同 `OverlayTargetForeColor_StaysBlackForAllThemes` |
| `Draw` が通常節 / 1 節扱い / 対象節でどちらの色を使うか | 同 `Draw_NormalClause_*` / `Draw_SingleClauseFallback_*` / `Draw_TargetClause_*` |
| 通常節と対象節が混在するとき、節ごとに色を引き直すこと | 同 `Draw_MixedNormalAndTargetClauses_UsesBothColors` |

**自動テストでは届かない範囲(ここを目視で見る)**

- 実際に**読めるか**(コントラスト・下線と文字の重なり・太字の潰れ)。テストが言えるのは
  「期待した色の画素が出た」までで、可読性は判定できない。
- 実 IME(MS-IME 等)が作る**本物の節構成**での見え方。テストは節構成を人工的に与えている。
- テーマ切替**直後**の反映(`ApplyAppearance` 経路が実アプリの設定ダイアログから通るか)。

### 0.2 手順

1. `feature/ime-overlay-theme-color` をビルドして起動する(Release 推奨)。
2. 日本語 IME を有効にする(半角/全角キー)。
3. テーマの切り替えは **設定ダイアログ → 表示 → 配色テーマ**。
4. 各テーマで次の 2 状態を作る:
   - **未確定(通常節のみ)**: 「にほんごにゅうりょく」等をかなで入力し、**変換キーを押さない**。
     下線だけが付いた状態。**ここが Issue #72 の症状が出る状態。**
   - **変換中(対象節あり)**: スペースキーで変換する。太字 + 水色背景の節が**対象節**、
     残りが通常節。`←` / `→` で対象節を移動すると、対象節と通常節の**混在**が見られる。

> ## ⚠ 「通常節」と「対象節」を取り違えないこと
>
> 本件で直したのは**通常節**(下線だけ・背景なし)。対象節(太字 + 水色背景)は
> **意図的に従来どおり黒**にしてある(設計書 §3: 背景がテーマ非連動の固定水色なので、
> テーマ色に連動させると逆に読めなくなる)。
>
> 「対象節が黒いままだ」は **FAIL ではない**。対象節が**水色地に白/黄/緑**になっていたら
> それが FAIL(退行)。

## 2. FAIL 時の扱い

- **通常節が依然として見えない** → `ApplyAppearance` を通らない経路(起動直後の既定テーマ等)が
  残っている疑い。どのタイミング・どのテーマで起きたかを記録する。
- **対象節が水色地に白/黄/緑になっている** → `OverlayTargetForeColor` の配線ミス。設計書 §3 の退行。
- **節ごとに色がばらつく** → `Draw` の節ループの問題。該当する入力文字列を逐語で記録する。

いずれも設計に戻る。項目 5 / 6 / 8 / 10(対象節)の FAIL は**退行**なのでマージしない。

---

## 3. 申し送り(このチェックリストの範囲外)

黒地テーマで**本文のテキストを選択**すると「水色地に白/黄/緑」で読めない。これは
`SelectionBack` がテーマ非連動の固定水色であることによる別の不具合(設計書 §7)で、
本ブランチの範囲外。目視中に気づいても本チェックリストの FAIL にはしない(別 Issue で扱う)。
