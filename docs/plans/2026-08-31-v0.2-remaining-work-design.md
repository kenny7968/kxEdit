## 2. 方針の分岐点と選択

L5 は 13 本分をまとめて 1 回で回すのが現実的で(監査 §8-5)、**実施後に src を触ると原理的に
やり直しになる**。したがって「L5 の前に src 修正をどこまで入れるか」が最初の意思決定になる。

- 案 A: すぐ L5 に入り、現状の main を確定版とみなす。最短でリリース可否が判る反面、
  **既知の虚偽発声とデータ破壊を抱えたまま**検証することになる。
- 案 B(**採用**): L5 を後回しにし、深刻度の高い修正を積んでから 1 回で回す。
  リリースは遠のくが、L5 の再実施リスクを最小化できる。

**ユーザー判断により案 B を採用**(2026-08-31)。

## 3. 本設計の芯 — 「Minor」ラベルを深刻度として読まない

監査 §6 の Minor 表は**発見時の分類であって深刻度ではない**。本設計の策定にあたり
残項目を実コードで再確認したところ、Minor 表の中に**データ破壊級**が混在していた。

| ID | 監査の分類 | 実際の性質 | 確認した実コード |
|----|-----------|-----------|-----------------|
| M-12 | Minor | **データ破壊**。`File.Replace` の部分失敗時に、唯一のディスク上コピーである tmp を消す | `Core/IO/AtomicFile.cs` の `catch { TryDelete(tmp); throw; }`(byte[] 版・Stream 版の両方) |
| M-25 | Minor | **データ破壊**。CSV F2 編集中の Ctrl+S で別位置を書き換える | `App/CsvController.cs` が `start`/`length` を編集開始時に捕捉し、`onCommit` でそのまま使用 |
| M-22 | Minor | **虚偽発声**。設定保存失敗でも「設定を適用しました」 | `App/MainForm.cs:1046-1047` が `SaveSettingsSafe()`(失敗を握る)の直後に無条件で `Say` |
| M-29 | Minor | 検索結果が黙って 0 件になる | `Core/Search/TextSearcher.cs` が `_regex.Matches(text)`(文書全体)の結果を `m.Index < s` で捨てるだけで、スコープ内での再照合をしない |
| M-9 / M-10 | Minor | 真に Minor | — |

同様に、PR #56 の申し送り(設計書 §9.10)にある**ゼロ幅ヒットのスコープ外書込**は
「成功発声つきでスコープ外へ書く」ため、データ破壊と虚偽発声を同時に踏む。

**したがって本設計は Minor 表を上から潰す方式を採らず、深刻度で並べ替える。**
この教訓は PR #53 で「Minor 指摘が Critical 級の事実を掘り当てた」のと同型である。

### 4.1 順序の根拠

**B1 を最初に置く。** `tools/pre-merge-check.ps1:51` に
「Core.Tests の Debug は**足さない**: 既知 S-5 で 4 件赤になり、ゲートが常時 NG になる」と
明記されており、Core.Tests は Release 構成でしか走っていない(同 `:35-36`)。
**以降 5 本すべてが今より弱いゲートで走ることになる**ため、最初に直す価値がある。
`Debug.Assert` は Release で消えるので、Debug でしか観測できない契約違反が丸ごと未検査。
設計書と実装計画はローカルブランチ `feature/wordboundary-maxscan-contract` に既にある。

**B2 → B3 を隣接させる。** 両者は根因が異なる(B2 = 巻き込み境界、B3 = 範囲の陳腐化)ため
1 ブランチにはしないが、どちらも PR #56 が導入した「**世代付きで保持して事後条件で検査する**」
パターンの適用先である。B2 で `ReplaceCharRangeExact` に「実際に書いた範囲」を問う seam を
足すと、B3 の検出面がその seam に乗る。逆順にすると B3 が独自の検出手段を作り、
B2 で作り直すことになる。

**B6 を最後に置く。** PR #57 の申し送りが
「`MarkdownPreviewForm.cs:89` を境界付きにすると監査 §9 の V-2(`.preview` の実 DNS 解決)を
踏ませる」と指摘している。つまり**この 1 行は V-2 の判断と同時にしか直せない**。

B4 と B5 は他への依存がなく、B1 の後であればどこに置いてもよい。
