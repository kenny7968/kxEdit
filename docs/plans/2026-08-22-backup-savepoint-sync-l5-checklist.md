## ① A-1 主経路 — 保存直後のクラッシュで新しい内容が残る

**手順**

1. 任意のテキストファイルを開き、`AAA` と入力する。
2. バックアップ間隔(30 秒)を待ち、`%APPDATA%\kxEdit\backups\session-*\` に `.json` が
   1 つできることを確認する。
3. さらに `BBB` と入力して **Ctrl+S**(保存成功)。
4. `.json` が**すぐ消える**ことを確認する(← A-1 第 1 層の即時反映)。
5. タスクマネージャーで kxEdit を強制終了する。
6. kxEdit を再起動する。

**期待**

- タブが **`AAABBB`(保存後の内容)** で開く。タブラベルに `*`(未保存)が付かない。
- 陳腐化警告ダイアログは出ない。
- NVDA がタブ名を読み上げるとき「アスタリスク」相当の未保存表示を読まない。

## ② A-1 第 2 層 — 陳腐化バックアップの警告が SR で読まれる

第 1 層(即時削除)は背景スレッドで動くため、削除がディスクへ届く前のクラッシュ窓が残る。
その状況を手で再現する。

**手順**

1. ① と同じ手順 1〜2 でバックアップ `.json` を作る。
2. `.json` をデスクトップ等へ**コピーして退避**する。
3. `CCC` を追記して **Ctrl+S**(`.json` が消える)。
4. 退避した `.json` を `%APPDATA%\kxEdit\backups\session-*\` へ**書き戻す**
   (= 削除がディスクへ届く前にクラッシュした状態)。
5. タスクマネージャーで強制終了 → 再起動。

**期待**

- 起動直後に **「復元した内容が古い可能性があります」** の警告ダイアログが出る。
- **NVDA がタイトル・本文・OK ボタンを読み上げる**(本文にファイルパスが 1 行で含まれる)。
- OK を押すと、タブは**バックアップ側の内容**(`CCC` を含まない)で `*` 付きで開く。
  = 本文は捨てない設計(ディスク版優先はしない)。
- ここで Ctrl+S せずにタブを閉じれば、ディスク上のファイルは `CCC` を含んだままである。

**結果**: ☐ PASS ☐ FAIL — 備考:

> FAIL の切り分け: ダイアログが**出ない**なら第 2 層の判定(`BackupStaleness` / `FileTimestampProvider`)、
> ダイアログは出るが**読まれない**なら WinForms の `MessageBox` と NVDA の相性
> (既存の `ShowFailedRestoreDialog` が同型なので、そちらも同時に確認する)。

## ③ M-31 — 破棄したタブが復活しない

**手順**

1. タブを 2 つ開く(A・B)。**両方**に編集を加える。
2. 30 秒待ち、バックアップ `.json` が 2 つできることを確認する。
3. **非アクティブな方**のタブを選び **Ctrl+W** → 未保存確認で **「いいえ」**(破棄)。
4. `.json` が**すぐ 1 つに減る**ことを確認する。
5. タスクマネージャーで強制終了 → 再起動。

**期待**

- 破棄したタブの**本文が復活しない**(空枠タブも出ない)。
- 残したタブは編集内容つき(`*` 付き)で復元される。
- NVDA が復元後のタブを正しく読み上げる。

## ④ ゲートの退行確認 — 前回セッションが従来どおり復元される

本修正で最も危険な退行は「起動時に空の無題タブでレイアウトを上書きし、前回セッションを失う」。
自動テスト(`MainFormSmokeTests`)で固定しているが、実機でも確認する。

**手順**

1. ファイルを 3 つ開き(うち 1 つは編集して `*` を付ける)、タブ順とアクティブタブを覚える。
2. **正常に**(ウィンドウの × で)終了する。
3. kxEdit を再起動する。

**期待**

- **3 つのタブが同じ順序で復元**され、アクティブタブも一致する。
- 編集していたタブは `*` 付きで内容が残る。
- 起動時の空の「無題 1」タブが**残らない**。
- 陳腐化警告は出ない。

**結果**: ☐ PASS ☐ FAIL — 備考:

## ⑤ バックアップ OFF / 復元 OFF での無影響確認

**手順**

1. [設定] で **「起動時に前回開いていたファイルを開く」を OFF**、**バックアップは ON** にする。
2. ファイルを開いて編集 → 30 秒待つ → Ctrl+S → 強制終了 → 再起動。

**期待**

- 従来どおり**復元提案ダイアログが出ない**(保存済みなのでバックアップは消えている)。
- 編集して**保存せずに**強制終了した場合は、従来どおり復元提案ダイアログが出て NVDA が読む。

## 判定

- ① または ③ が FAIL → 第 1 層(即時反映)の配線を疑う。`BackupCoordinator.OnCleanedOrClosed` と
  `MainForm.OnShown` の `MarkStartupRestoreComplete()`。
- ② が FAIL → 第 2 層のみ切り離してマージする判断もありうる(第 1 層だけでも A-1 の主経路は直る)。
- **④ が FAIL は即マージ中止**。前回セッションの喪失は A-1 より重い退行。
  該当コミットは「起動時復元後に即時反映を有効化し、陳腐化バックアップを警告する」。

総合: ☐ マージ可 ☐ 要修正
